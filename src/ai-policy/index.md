# AI Policy

I believe that using LLMs to generate blog posts is a grave sin for a variety of reasons, even using them to reword things is questionable, although spelling and grammar checking is fine. I don't have quite the same hangups about using LLMs to write and edit code, especially if it is code I have written many times before. Code that is meant to be read, such as examples, falls under the same restrictions as prose. 

So you can rest assured, dear reader, that you will never have to read or see anything AI generated on my website, but some HTML tags, GPU context initializations, CSS values etc. may not have been entirely hand written. I can only beg for your understanding and forgiveness.

I will update this document if my attitudes change.
